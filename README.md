# JellyJump

**JellyJump** is a modern, feature-rich video player and basic video editor powered by **MediaBunny**. It runs entirely in your browser with complete privacy, allowing you to play local files, stream HLS, trim videos, convert formats, and create GIFs without uploading your data.

## Features

-   **Local Playback**: Play video and audio files directly from your device.
-   **Stream Support**: Native HLS (.m3u8) streaming support.
-   **Video Editing**: Trim, crop, and convert videos locally.
-   **GIF Creation**: Create high-quality GIFs from your videos.
-   **Privacy First**: No data is uploaded to any server; everything happens in your browser.
-   **PWA Support**: Installable as a Progressive Web App for a native-like experience.

## Quick Start

You can run JellyJump locally using any static file server.

### Using Node.js
```bash
npm install
npm run dev
```
Visit `http://localhost:8080` in your browser.

### Using Python
```bash
python3 -m http.server 8080
```
Visit `http://localhost:8080` in your browser.
